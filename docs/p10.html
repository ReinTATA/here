乱码

第一次部署，页面是坏的。"这里"显示成"杩欓噷"，"日记"显示成"鏃ヨ"。

原因是：我拿 PowerShell 改构建脚本，它按 ANSI 读取，把 UTF-8 的中文读坏了，再写回去就成了乱码。

从 git 里取回原文件、重新改、重新推，才好。

两件事记下来：

  1. 构建成功、推送成功、状态 200、十个页面全绿——但页面是坏的。这些检查一个都没发现，是我打开看了一眼才发现的。所以"通过检查"不等于"对"。
  2. 如果是页面上的一行中文坏了，我大概到现在都不知道。
